# 泡泡花園 Bubble Garden

### 👉 [點這裡開始玩](https://sdfvgv1994-bot.github.io/taco-bubble/)

網址：https://sdfvgv1994-bot.github.io/taco-bubble/ （電腦、手機都能玩）

泡泡龍玩法的網頁小遊戲：發射泡泡，讓 3 顆以上同色連在一起就會消掉，吊在下面的泡泡跟著掉落有額外分數。

- 6 種模式：經典花園、闖關 50 關、下降闖關 50 關、限時 60 秒、限球 25 顆、下降挑戰
- 電腦：滑鼠瞄準、點一下發射，空白鍵直直往上射
- 手機：手指按住拖曳瞄準（會顯示含撞牆反彈的路線），放開發射；拖到發射台下面放開＝取消
- 最高紀錄存在自己的裝置；切到別的 App 會自動暫停

main 有更新時，GitHub Actions 會先跑測試（`pytest`，遊戲規則用 node 執行），通過才自動上線到 GitHub Pages。

## 程式積木

程式拆成幾個小積木，每塊只管一件事，要改哪塊就只動那塊：

| 檔案 | 負責 |
|---|---|
| `index.html` | 畫面骨架，照順序載入下面的積木 |
| `style.css` | 樣式（電腦、手機直拿、橫拿） |
| `js/elements.js` | 畫面上的元件（分數、按鈕、選單、畫布） |
| `js/config.js` | 固定設定：欄數、6 種模式、泡泡顏色、音樂旋律 |
| `js/state.js` | 遊戲狀態：盤面、分數、最高紀錄、瞄準、暫停 |
| `js/sound.js` | 音效和背景音樂 |
| `js/board.js` | 蜂巢盤面規則：位置、鄰居、同色相連、懸空掉落、找空位 |
| `js/flight.js` | 發射台、泡泡飛行和瞄準線（預測落點＝實際落點） |
| `js/draw.js` | 把畫面畫到畫布上 |
| `js/game.js` | 關卡、回合、計分、下降、勝負和主迴圈 |
| `js/input.js` | 滑鼠、手指、鍵盤和按鈕 |
| `js/main.js` | 最後開局 |

載入順序寫在 `index.html`，後面的積木會用到前面的，不能亂換；`main.js` 一定在最後。新增積木要一起加進 `index.html` 和 `tests/test_game.py` 的 `BLOCKS`。上線時每個檔案後面的 `?v=dev` 會換成版本號，手機才不會新舊檔混用。
