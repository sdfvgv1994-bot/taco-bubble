# 泡泡花園 Bubble Garden

泡泡龍玩法的網頁小遊戲：發射泡泡，讓 3 顆以上同色連在一起就會消掉，吊在下面的泡泡跟著掉落有額外分數。

- 6 種模式：經典花園、闖關 50 關、下降闖關 50 關、限時 60 秒、限球 25 顆、下降挑戰
- 電腦：滑鼠瞄準、點一下發射，空白鍵直直往上射
- 手機：手指按住拖曳瞄準（會顯示含撞牆反彈的路線），放開發射；拖到發射台下面放開＝取消
- 最高紀錄存在自己的裝置；切到別的 App 會自動暫停

main 有更新時，GitHub Actions 會先跑測試（`pytest`，遊戲規則用 node 執行），通過才自動上線到 GitHub Pages。
